# Bundle Builder

A React + Vite + TypeScript prototype for the Frontend Take-Home Bundle Builder.

## Run

```bash
npm install
npm run dev
```

## Verify

```bash
npm run build
npm run lint
```

## Notes

- The UI is driven from local JSON seed data so the layout and summary render from a single source of truth.
- The current milestone focuses on the static desktop layout and seeded summary state; interaction logic can be layered in next.
- The connected Figma file was not accessible through the current MCP account, so the implementation follows the written spec and the seeded UI state rather than exact extracted design tokens.
